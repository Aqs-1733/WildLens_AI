# Monitoring Report Skill

## Purpose
Generate a traceable monitoring report from database statistics and reviewed events.

## Sections
- Monitoring scope and source video
- Species observations with scientific names
- Activity timeline
- Risk events and review result
- Data/model limitations
- Patrol or education recommendations

## Constraints
No unsupported claim. Distinguish synthetic demo media, public dataset samples, user uploads and real monitoring evidence. Include model versions and confidence ranges.
