# 墨刀原型规划

建议新建PC网页原型，画布按1440×900；建立“公共组件”母版：左侧导航、顶部栏、统计卡、物种卡、视频标注框、弹窗、加载/空/错误状态。

## 页面分组

### 账号
- 登录
- 注册（公众/监管邀请码）
- 找回密码作为后续增强，不在当前代码中虚假标记完成

### 公众端
- 综合首页
- 视频识别
- 分析任务
- 物种百科
- 观察收集册
- 学习挑战
- 好友与分享
- 智能科普
- 生态数据

### 监管端
- 风险预警
- 人工复核
- AI报告
- 模型中心
- 数据集管理

## 核心交互连线

1. 登录 -> 首页。
2. 首页“体验示例” -> 视频识别。
3. 播放器彩色框 -> 物种弹窗。
4. 弹窗“问AI” -> 同弹窗问答标签页。
5. 完成学习 -> 星星奖励 -> 收集册亮起。
6. 风险卡 -> 事件详情 -> 确认/驳回。
7. 低置信度目标 -> 人工复核 -> 加入训练集。

原型交付时打开开发标注，导出关键页面PNG，并保留在线评论与版本记录。
