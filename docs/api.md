# API摘要

- `POST /api/auth/register`、`POST /api/auth/login`、`GET /api/auth/me`
- `GET /api/dashboard`
- `POST /api/videos/upload`、`GET /api/videos/jobs`、`GET /api/videos/jobs/{id}`、`GET /api/videos/jobs/{id}/detections`
- `GET /api/species`、`GET /api/species/collection`、`POST /api/species/{id}/collect`
- `GET /api/species/learning/tasks`、`POST /api/species/learning/tasks/{id}/claim`
- `GET /api/social/friends`、`POST /api/social/friends/request`、`GET /api/social/feed`、`POST /api/social/posts`
- `POST /api/qa/ask`
- `GET/PATCH /api/alerts`
- `GET /api/review/queue`、`PATCH /api/review/detections/{id}`
- `GET /api/reports/jobs/{id}`
- `GET /api/system/models`、`GET /api/system/datasets`

完整交互模式以运行后的 `/docs` 为准。
