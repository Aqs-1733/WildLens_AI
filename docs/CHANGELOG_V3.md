# WildLens AI V3 真实识别重构变更

- 视频统一生成 H.264/AAC/yuv420p/faststart 播放版本；
- 原始、播放、标注视频分离存储；
- 新增 `video_tracks` 与 `track_keyframes`，前端插值绘制随目标移动的边框；
- 普通自然问题和目标问题直接调用 ARK，知识库仅作增强；
- 取消预设个人图鉴、固定完成度和未解锁剪影；
- 仅在用户确认后创建观察记录，每次重复发现独立保存；
- 新增 GPS/地点/隐私字段和动物、植物真菌、自然现象三层中国地图；
- 新增一万类 `taxa` 数据结构、分类层级、同义名、相似物种、开放许可图片；
- 新增 iNaturalist 2021 mini/full 下载、层级训练、断点续训、Top-5、unknown 与 ONNX 导出；
- 本地检测器、细粒度 ONNX 分类器与 ARK 可组成检测—裁剪—定种—解释链路；
- 新增旧数据库与旧视频升级脚本。
