# 答辩演示流程

1. 用 `explorer / Wild1234!` 登录公众端。
2. 首页展示公众学习数据，打开“视频识别”。
3. 选择内置离线演示视频，播放时看到动物与植物不同颜色的可点击框、学名和置信度。
4. 点击“梅花鹿”框，查看分类、保护、当前视频观察与相似物种知识。
5. 在同一弹窗问“为什么它停在原地”，展示带上下文的AI回答和不确定性说明。
6. 打开收集册，展示已解锁/未解锁卡片、知识进度、星星和奖励。
7. 完成学习任务，领取积分与星星。
8. 打开好友与分享，发布观察记录、点赞和查看好友。
9. 退出并用 `ranger / Wild1234!` 登录监管端。
10. 打开风险预警与人工复核，确认或驳回目标并演示“加入训练集”。
11. 下载PDF报告，查看模型和数据集登记页。
12. 说明内置视频是合成离线演示；真实数据通过WCS、Pl@ntNet、D-Fire脚本分批下载训练。
