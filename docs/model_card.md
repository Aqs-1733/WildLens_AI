# 模型卡

## 默认模式

默认代码包不捆绑大型权重。上传视频时使用OpenCV运动/颜色候选区与有限ARK视觉复核，适合验证产品流程，不应当作专业生态调查结果。

## 可选专业模式

- MegaDetector：动物、人员、车辆候选框。
- SpeciesNet：相机陷阽物种分类。
- 自训练ONNX：目标保护区物种、植物、火烟。
- ByteTrack/BoT-SORT：生产级目标追踪。

## 限制

- 植物在广角森林视频中通常是背景，可靠识别集中于近景、显著主体或用户框选区域。
- 遮挡、红外、雨雪、逆光、远距离和相似物种会降低准确率。
- 模型置信度不是法律证据；高风险和低置信度结果必须人工复核。
- 指标必须在按相机点位隔离的测试集上报告；未生成权重时界面显示“待训练”，不伪造数值。
