# 数据许可与来源记录

本目录用于保存每个外部数据集、模型权重和参考图片的许可快照、引用信息与下载日期。

项目源码压缩包不直接打包百万级外部数据，也不重新分发受限数据。下载脚本只根据官方入口建立可复现的子集；执行下载前应阅读并接受对应数据集条款。

建议每次导入数据时新增一个记录文件，至少包含：

- 数据集名称与版本
- 官方页面和下载地址
- 许可名称或研究用途限制
- 下载日期
- 选取类别与样本数量
- 原始文件校验值
- 是否允许重新分发
- 论文或项目引用格式

当前数据源登记见 `data/manifests/dataset_sources.json`，详细训练计划见 `docs/dataset_plan.md`。
